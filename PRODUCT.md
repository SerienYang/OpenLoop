# Product

## Register

product

## Users

OpenLoop serves technical and operational professionals who use a desktop agent for sustained
work across code, documents, connectors, and automation. They value speed, precision, readable
density, and predictable controls over decorative presentation.

## Product Purpose

OpenLoop provides one local desktop runtime for planning, execution, approvals, artifacts,
connectors, and scheduled work. The interface should make the runtime understandable and
controllable without competing with the work itself.

## Brand Personality

Cold, precise, engineering-led.

## Anti-references

- Generic blue SaaS dashboards.
- High-saturation accents used as decoration.
- Inconsistent native controls, novelty icons, and visually noisy cards.
- Decorative gradients, glass effects, and friendly mascot styling.
- Interfaces whose labels or layout shift unpredictably between languages.

## Design Principles

1. Make state and hierarchy legible before adding decoration.
2. Use one consistent interaction vocabulary across the whole app.
3. Keep information dense but aligned, with deliberate spacing and stable control columns.
4. Treat localization as a complete product state, not a partial overlay.
5. Keep OpenLoop visually restrained so the user's work remains primary.

## Accessibility & Inclusion

Target WCAG AA contrast. Preserve semantic controls, visible keyboard focus, descriptive labels,
and reduced-motion compatibility. Layouts must tolerate Chinese and English text without clipping,
misalignment, or loss of hierarchy.
